Data Security

🔒 Local Processing

All data processing happens on your machine. Files are stored locally in the storage/ directory and never leave your network.

🛡️ Schema-Only AI

Only column names, data types, and small samples are sent to the AI. Your actual data rows are never transmitted to external APIs.

🧹 Auto Cleanup

Uploaded files and generated workbooks can be purged at any time. No persistent cloud storage is involved.

Frequently Asked Questions

What file formats are supported?▼
ExcelFlow accepts .csv, .xlsx, and .xls files up to 25MB. For questions, you can paste text directly or upload .pdf, .docx, .txt, and image files (.png, .jpg, .webp).
Do I need an API key?▼
A Gemini API key is required for AI-powered plan generation. Without it, ExcelFlow falls back to a smart NLP architect that still produces quality dashboards using rule-based analysis.
Are the formulas real or just static values?▼
100% real. Every KPI, breakdown table, and calculated column uses live Excel formulas (SUMIFS, AVERAGEIFS, COUNTIFS, structured table references). If you update the raw data, the dashboard recalculates.
What does "zero hallucination" mean?▼
Every column name the AI references is validated against your actual dataset schema using fuzzy matching. If the AI suggests a column that doesn't exist, it's auto-corrected or removed — never fabricated.
Can I customize the dashboard layout?▼
Yes. Describe exactly what KPIs, analyses, charts, and filters you want in your business question. The AI will structure the plan to match your specifications.
Does it work on Mac/Linux?▼
The core workbook generation (formulas, charts, formatting) works on all platforms. Native PivotTables and Slicers require Windows with Excel installed (Win32COM), but the fallback openpyxl tables work everywhere.
